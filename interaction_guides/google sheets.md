# Google Sheets (Chrome, docs.google.com/spreadsheets)

**Purpose.** Один из основных инструментов для ведения таблиц. Отсюда мы ведём месячный учёт финансов
(файл «Финансы — карты, долги, платежи»).

**Window & focus.** Отдельного процесса нет — это вкладка Chrome (`chrome.exe`). Определять по заголовку
окна: `<имя файла> - Google Sheets - Google Chrome`. Кириллическое имя файла в заголовке UIA отдаёт
корректно; OCR заголовка — «ломает» буквы.

## Main areas (координаты — окно 1920×1080, максимально, ПРИМЕРНЫЕ: баннер Drive вверху сдвигает всё на ~56 px)
- **Название файла** — верхний левый угол ≈ (62…350, 159…176). Клик по нему открывает меню файла,
  либо: меню **File** → **Rename**.
- **Строка меню** — File Edit View Insert Format Data Tools Extensions Help, y ≈ 183…194
  (File ≈ x 63…84, Edit ≈ 101…127, View ≈ 143…166, Insert ≈ 178…215, Format ≈ 230…270, Data ≈ 285…315,
  Tools ≈ 349…382).
- **Тулбар** — y ≈ 221…238: «Menus» (☰), undo/redo, zoom, формат чисел («.00», «123», «Default…»).
- **Name box** (поле адреса ячейки/диапазона) — ≈ (12…120, 258…282). Самый надёжный способ перейти
  к диапазону: клик → Ctrl+A → ввести, например, `A1` или `1:1` → Enter.
- **Полоса формул** — справа от name box, y ≈ 258…282.
- **Сетка** — начинается ≈ (42, 314). Колонка A ≈ x 42…142, строка 1 ≈ y 314…335, шаг строк ≈ 21 px.
- **Вкладки листов** — внизу слева, y ≈ 1027…1038 («Sheet1»).
- **Правая панель «Tables»** — x ≈ 1600…1930 (Featured/Blank table/…). Может быть открыта по умолчанию,
  съедает ширину; закрывается по «x» в её углу.

## Key controls / что реально работает
- **Создать новую таблицу:** в омнибоксе Chrome набрать `sheets.new` + Enter → создаётся пустая таблица
  (проверено 28.09.2026). Заголовок окна сразу `Untitled spreadsheet - Google Sheets`.
- **Переименовать:** File → Rename → диалог с уже выделенным именем → напечатать новое → Enter.
  Заголовок окна и облако обновляются, в правом верхнем углу появляется «Saved to Drive».
- **Вставка множества ячеек:** подготовить TSV (табы — столбцы, переводы строки — строки) в буфер обмена
  и нажать Ctrl+V в A1 — Sheets разложит по ячейкам. Проверено на 15×10. Удобнее, чем печатать по ячейкам.
- **Перейти к A1:** Ctrl+Home (когда фокус в сетке). Признак, что фокус в сетке: активная ячейка с синей
  рамкой, name box показывает её адрес.
- **Проверка, что числа распознаны:** числа выравниваются по **правому** краю (текст — по левому).
  Формат «3 673,52» (пробел как разделитель тысяч, запятая — десятичная) распознаётся как число ✓.
- **Прочитать содержимое:** UI Automation по сетке пуст (canvas). OCR по окну работает, но цифры «плывут»
  (`28.09.2026` → `28 09Q026`), поэтому для сверки лучше `vision_look` по узкому прямоугольнику сетки.

## Shortcuts
- Ctrl+Home — A1 · Ctrl+B — жирный · Ctrl+V — вставка TSV-блока · Ctrl+Z — отменить вставку
- Ctrl+Shift+V — вставить как значения (если нужно без форматов)

## Reading app state
- Заголовок окна: `<имя файла> - Google Sheets - Google Chrome` → по нему видно, открыт ли нужный файл.
- В правом верхнем углу — «Saved to Drive» / «Saving…» — индикатор сохранения.
- Name box показывает адрес выделения (например, `A1:J15` после вставки — удобная проверка размера блока).

## Gotchas
- Баннер Drive «70% of storage used … Get more storage» появляется сверху (y ≈ 109…123) и **сдвигает всю
  вёрстку вниз** — координаты из этой инструкции после его появления надо сдвинуть на ~+56 px.
- Клик по пустому месту шапки может «съесть» нажатие (первый клик по названию файла может уйти в баннер).
- UIA даёт только `Pane`, без сетки — не тратить время на поиск контролов, работать мышью/OCR/vision.
- OCR кириллицы и латиницы в одном окне сильно врёт («Интернет-банк» → `YIHTepHeT-6BHK`).
- Выделение всей строки кликом по её номеру в этой сессии не подтвердилось — использовать name box (`1:1`).

- **Переход к ячейке (проверено 28.09.2026):** name box ненадёжен при клике мышью — в двух попытках клик
  (60,269) и (30,269) не попадал в поле, Ctrl+A + набор текста уходили в сетку и портили ячейки. Надёжнее:
  клик в сетку → Ctrl+Home (A1) → стрелки, но **стрелки, отправленные очередью в одном шаге, теряются**
  (из 6 «вправо» применилось 1–2) — двигать по одной с проверкой name box через OCR.
- **Ctrl+A/Ctrl+C + clipboard:** Google пишет в буфер **асинхронно** — после Ctrl+C подождать 1–2 с,
  иначе clipboard вернёт старое содержимое. Проверка: `clipboard_get` после паузы.
- **Вставка TSV:** Ctrl+V в выбранную ячейку раскладывает блок по строкам/столбцам ✓ (это самый быстрый
  способ залить много данных). Перед вставкой ОБЯЗАТЕЛЬНО проверить адрес активной ячейки.
- **Откат:** Ctrl+Z отменяет по одной вставке ✓ (проверено — восстановило испорченные строки).

- **Таблица «Финансы — карты, долги, платежи» (проверено 28.09.2026).** Правильный ID документа:
  `1JAKlZdbMPQZ_tC3CRrJVywTXVVZKK1SFnSCz_YtIx64` (лист gid=0). ВНИМАНИЕ: ID читается с экрана с ошибками
  (`I`↔`1`, `l`↔`I`) — мой первый записанный ID был неверным, Google отвечал «файл не существует».
  Проверять ID в `chrome://history` (там настоящий URL в clipboard-выдаче), а не глазами.
  Структура: A Дата снятия · B Месяц · C Банк · D Продукт · E Тип · F Доступно, ₽ · G Задолженность, ₽ ·
  H Мин. платёж, ₽ · I Срок платежа · J Лимит, ₽ · K Комментарий. Строки 2–15: Т-Банк (Black, Платинум,
  Потребкредит), РСБ (4 карты), РСБ (3 кредита), Халва, Альфа, ВТБ, Сбер.
- **КАК НАДЁЖНО ПИСАТЬ В ЯЧЕЙКИ (рабочий метод, проверен 28.09.2026):**
  1) `clipboard_set` с URL вида
     `https://docs.google.com/spreadsheets/d/<ID>/edit?gid=0#gid=0&range=F2:J15` → Ctrl+L → Ctrl+V → Enter.
     При загрузке Sheets САМ выделяет указанный диапазон — это самый надёжный способ попасть в нужные ячейки
     (name box потом показывает, например, `F2:J15`; проверять через `vision_look(rect=[0,248,200,292])`).
  2) `clipboard_set` с TSV-блоком нужного размера → Ctrl+V. Вставка идёт в левый верхний угол выделения.
  3) Проверка: Ctrl+A → Ctrl+C → пауза 1–2 с → `clipboard_save` → сверить с ожидаемым.
- **Ловушка вставки:** если в TSV-строке есть «висячие» пустые поля в конце, широкий блок может затронуть
  соседний столбец (в моём случае очистились K14:K15). После вставки широкого блока ВСЕГДА проверять соседний
  столбец справа.
- **Числа:** русская локаль. Вставка `164 409,00` (обычный пробел как разделитель) парсится как ЧИСЛО и даёт
  формат с разрядами; вставка `164409,00` — тоже число, но без разрядов (формат ячейки меняется на «без
  группировки»). Чтобы сохранить вид таблицы, вставлять числа с пробелами-разрядами.
- **Никогда не набирать URL/адреса ячейки вручную клавиатурой:** keybd_type иногда теряет первые 1–2 символа
  (`https://…` → `tps://…`, из-за чего Chrome уходил в поиск). Только через буфер обмена (Ctrl+V).
