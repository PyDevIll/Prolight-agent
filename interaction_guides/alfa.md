# alfa — Альфа-Банк, «Альфа-Онлайн» (web.alfabank.ru)

## Purpose
- Интернет-банк **Альфа-Банка**: https://web.alfabank.ru/… — DOM-приложение *внутри Google Chrome*
  (процесс `chrome.exe`). Заголовок окна `Альфа-Онлайн - Google Chrome` (вкладка может называться
  иначе) — страницу определяет URL.
- Проверенные страницы: `/dashboard/` (дашборд, стартовая), `/accounts/<номер счёта>` (страница счёта
  карты — здесь видна **задолженность**), а также ссылки `/payments/payments-and-transfers`,
  `/history/`, `/chats/`, `/marketplace/`.
- Выполнялись только чтение и навигация. **Никаких платежей/переводов/изменений не делалось.**

## Reading app state
- Суммы/статусы — только OCR (`win_snapshot` с `region` или `include=["text"]`), a11y-текст их не содержит.
- Левая панель «Мои продукты» есть на **всех** страницах (и на дашборде, и на странице счёта), поэтому
  она не различает состояния — различают только блоки центральной колонки.
- Признаки роутера (v2): `account` ⇔ `Мои продукты` + любое из
  (`Общий долг` · `задолженность` · `Реквизиты счёта` · `Периоды без процентов` ·
  `изменить кредитный лимит` · `Увеличить период`) — набор избыточен специально: страница счёта
  прокручивается, и на разных позициях видны разные из этих надписей;
  `dashboard` ⇔ `Быстрые переводы` + (`Для вас`/`Деньги за рекомендации`/`Быстрые платежи`);
  иначе `fallback`.
- Внимание: `Общий баланс` есть и на дашборде, и в левой панели страницы счёта — как признак состояния
  его использовать нельзя (была ложная маршрутизация на дашборд; исправлено в v2).

## Gotchas
- Левая панель «Мои продукты» есть на всех страницах, но суммы в ней — только у строк продуктов.
- `Пополнить`, `пропустить платёж`, `Автопогашение`, `закрытие счёта`, `изменить кредитный лимит` —
  **денежные/необратимые действия**: сначала спрашивать пользователя.
- Заголовок вкладки/окна не отражает страницу — проверяйте URL (`win_read_text` отдаёт его даже когда
  текст страницы пуст).
- Названия в левой панели и на странице счёта меняются местами (`Счет кредитной карты` — и раздел, и
  строка) — ищите по игле и позиции, а не по точному совпадению.

## Вход в кабинет
- **Вход в кабинет** (записано 28.09.2026): новая вкладка → `https://alfabank.ru/` → вход
  «**Мобильный банк Альфа-Онлайн**» (экран входа, титул «Мобильный банк Альфа-Онлайн») → логин/пароль
  (вводит пользователь) → кабинет `https://web.alfabank.ru/` (титул «Альфа-Онлайн»).
- Chrome предлагает сохранить пароль → отвечали **«Никогда»**.
- «Мобильный банк Альфа-Онлайн» ≠ «Альфа-Онлайн»: первое — вход, второе — уже кабинет.
- Общий сценарий — workflow `вход_в_лк_банка`.

- Вход настроен на **короткий код вместо пароля** (по замыслу пользователя — чтобы агент входил сам):
  на экране входа «Мобильный банк Альфа-Онлайн» вводится 4-значный код (значение — `secrets/bank_codes.md`),
  логин подставляет браузер. Пароль агент не знает и не должен.
- Ввод: клик в поле кода → `keybd_type` цифрами → проверка, что поле заполнилось → Enter. Одна попытка.
