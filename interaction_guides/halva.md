## Reading app state
- `win_read_text(hwnd)` → URL + тексты (историю операций отдаёт чистой кириллицей).
- Деньги/суммы в карточке на a11y-текст **не попадают** — читать OCR-ом (`win_snapshot` с `region`).
- Признаки состояний роутера: `card_balance` ⇔ `заемные` + (`пополнить`/`график`/`Ближайший`);
  `history` ⇔ `История операций` + (`Успешные`/`Поиск по истории`); иначе `fallback`.

## Gotchas
- Заголовок окна не меняется — навигацию проверяй по URL из `win_read_text`.
- OCR этой страницы охотно читает русский как латиницу, а подписи у иконок (`Фильтр`, `период`,
  `о платеже`) — с ошибками; доверяй a11y-тексту и числовым/уникальным подстрокам.
- Колесо мыши не прокручивает страницу, если курсор над шапкой — двигай курсор в контент.
- ЛК сохраняет прежнюю позицию прокрутки при переходе на другую страницу (координаты «уезжают»).
- `пополнить`, `Управлять подпиской`, `оплатить`, оформление продуктов — **денежные операции**:
  спрашивать пользователя.
