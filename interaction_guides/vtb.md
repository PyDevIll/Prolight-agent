# vtb — ВТБ Онлайн (online.vtb.ru)

## Purpose
- Интернет-банк **Банк ВТБ (ПАО)**, «ВТБ Онлайн»: https://online.vtb.ru/… — DOM-приложение *внутри
  Google Chrome* (процесс `chrome.exe`). Заголовок окна — SEO-строка сайта
  (`Интернет-банк ВТБ Онлайн: вход в личный кабинет - Google Chrome`), поэтому страницу определяет
  только URL.
- Проверенные страницы: `/home` (главная), `/history` (история операций), `/products` (витрина
  продуктов). Также в левом меню: «Платежи», «Справки», «Открыть новый продукт».
- Выполнялись только чтение и навигация. **Никаких платежей/переводов/оформлений не делалось.**

## Window & focus
- `win_ensure_foreground(656810)` перед вводом; окно максимизировано 1920×1080 в [-8,-8].
- Роутер автовыбором даёт `chrome` (хвост заголовка «Google Chrome») → работаем явно:
  `route_app_state(app="vtb")`, `resolve_app_control(name, app="vtb")`,
  `execute_app_control(name, app="vtb")`.
- `win_read_text(hwnd)` отдаёт URL + часть текста; **суммы в главном блоке карты в a11y-текст не
  попадают** — их надо читать OCR-ом (`win_snapshot` / OCR-регион). Заголовки дней в истории в
  a11y-тексте проговариваются словами («…сумма расходов за день триста шестьдесят девять рублей»),
  цифры точнее в OCR.

## Gotchas
- Названия разделов в левом меню совпадают с заголовками блоков на странице (напр. `Платежи`
  в меню y333 и блок `Платежи и переводы` y688) — игла должна попадать в меню (первое совпадение по Y).
- `/history` и другие страницы SPA подгружаются асинхронно — пустой OCR сразу после клика это норма,
  надо повторить снапшот.
- `Пополнить счет`, `Перевести`, `Забрать тут`, оформление продуктов — **денежные действия**:
  сначала спрашивать пользователя.
- В истории операций бывают отклонённые операции (`Операция отклонена`) — не считать их расходом.

## Вход в кабинет
- **Вход в кабинет** (записано 28.09.2026): новая вкладка → `https://vtb.ru/` → «Войти» → страница
  «**Интернет-банк ВТБ Онлайн: вход в личный кабинет**» → логин/пароль (+ возможно код — вводит
  пользователь) → кабинет `https://online.vtb.ru/`.
- Самый длинный вход из шести банков (в записи 8 отдельных состояний на одну авторизацию).
- Общий сценарий — workflow `вход_в_лк_банка`.

- Схема входа (подтверждено пользователем): **код входа** (короткий, вместо пароля — значение
  в `secrets/bank_codes.md`) → банк **всё равно просит код из СМС** (одноразовый, каждый раз новый).
  Поэтому ВТБ агент доводит только до запроса СМС, последний шаг — пользователь.
- Порядок полей на экране входа: 1) код входа, 2) код из СМС.
